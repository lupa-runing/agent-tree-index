# PageIndex 前端样式优化

## 目标

参考创作神经网络看板的深灰、银灰、香槟金及柔和辉光，优化知识库文档问答工作台。重点保持阅读舒适、信息层级清晰与现有操作习惯。

## 页面与视觉

- 保留知识库及文档侧栏、中央对话区、可收起的历史面板。
- 侧栏加入 PageIndex 品牌、明确的分区标题、文档上传入口和本地运行状态；模型设置保留。
- 欢迎页使用 CSS 与 SVG 绘制抽象知识光球及连接节点，提供可填入输入框的提问建议。
- 对话使用低饱和半透明面板，区分问题、答案、推理过程与引用来源。
- 使用统一颜色变量、圆角、边框与焦点样式；窄屏通过侧栏开关访问知识库，历史面板作为浮层展开。
- 支持减少动态效果偏好，所有装饰图形不参与键盘焦点。

## 功能边界

沿用现有模型调用、索引和持久化格式；补充知识库关联与单篇文档信息的只读接口。上传入口、知识库选择、对话切换、引用与推理展开继续使用原有功能。提问建议仅填入输入框，不自动发送请求。

## 验证

执行 Python 编译和前端脚本语法检查；在浏览器查看欢迎页、知识库选中状态、历史面板、文档列表与窄屏布局。验证过程不上传、删除文档或发起模型请求；比对持久化文件校验值。

## 知识库导航与星团视图

### 导航与页面

顶部胶囊导航新增“知识库”，工作台与知识库页面通过地址 hash 切换，支持刷新恢复以及浏览器前进、后退。知识库页面展示全部知识库，支持按名称搜索，在常规列表和星团两种视图间切换，视图偏好保存在当前浏览器。

列表模式点击知识库进入表格详情；星团模式点击知识库后在原场景内扇形展开文档，点击文档打开信息弹框。两种模式均提供添加文档及进入该库问答的入口。详情支持返回知识库页面，保留筛选与视图状态；不修改现有文档或会话存储格式。

### 关联依据

增加只读的知识库关系接口，根据同名文档和知识库名称、文档名称、章节标题中的共同关键词生成关联。只使用已存储的资料，不调用模型；连线可查看具体关联依据，没有依据时不绘制连线，不将视觉上接近的星团视为关联。

默认按同名文档或至少两个有效共同关键词判断关联，过滤常见目录词和过短词。关系为规则推导结果，不表示已完成全文语义理解。

### 星团表现

直接复用 neural-creator-dashboard 的视频素材和 React Scene 场景代码：透明视频在原位播放、Canvas 逐帧绘制，保留原版遮罩、混合模式、配色滤镜、光晕、光尘、弹簧运动及 SVG 往返脉冲。移除自行绘制的粒子球、三角网格水母与旧动画类。

知识库使用原版水母和玻璃标签，名称、文档数和真实关联来自当前 PageIndex 数据。原固定五模块布局只适配动态数量、现有页面宽度和手机标签边界。中心至水母的光丝表达空间归属，金色库间连线仅绘制已有规则推导的真实关联；名称与节点均支持点击，水母按钮可通过键盘访问。

前端源文件位于 frontend/neural，构建后由 FastAPI 提供本地静态资源，不需要单独启动 Vite 服务。常规列表、模型管理和工作台继续使用现有实现。

### 验证边界

检查导航、两种视图、筛选、知识库详情、文档列表、问答跳转和响应式布局。验证关联规则的正例和无关联场景，不修改现有知识库数据或调用模型。

## 星团内展开与文档弹框

- 星团模式点击知识库时，在同一场景内展开：中心光球退到左侧，知识库星团纵向排列，当前库高亮，其文档节点通过柔和曲线向右扇形展开。支持切换左侧知识库、通过面包屑或 Esc 返回全部星团。
- 常规列表模式继续使用现有知识库详情页，不改变表格、文档搜索和问答入口。
- 点击扇形文档节点打开原生模态弹框，展示文件名、所属知识库、格式、已有页数、文档说明和已索引的章节树及摘要。关闭弹框后保留展开场景，支持关闭按钮、Esc 和遮罩关闭。
- 新增单篇文档信息的只读接口，仅返回已有索引与展示字段，不暴露磁盘路径，不请求模型、不重新索引、不改变持久化格式。缺失元数据明确显示未记录。
- 动画尊重减少动态效果偏好；窄屏改为纵向展开，文档节点和弹框均可访问。验证星团返回、库间切换、文档弹框、列表原交互、响应式布局及文件校验值。

## 星团详情切换动画修正

从总览进入详情时保留核心球向左退场、星团归位的入场动画；详情内切换知识库时保留核心球的位置和大小、其他知识库节点位置及滚动位置，仅反馈选中星团并重新展开文档分支。加载期间保留当前画面，不重播核心球从右向左穿越的动画；文档数量变化导致画布高度变化时，核心球仍保持原位置。

## 直接复用 neural-creator-dashboard 原版场景

本次替换自行绘制的水母和核心球，直接复制本地 neural-creator-dashboard 的 Home.jsx 场景代码、theme.js 配色、neural.css 场景样式，以及 orb.mp4／jellyfish.mp4 和封面图。保留原版视频逐帧绘制到 Canvas、弹簧运动、往返光脉冲、光晕与光尘；不重新仿画素材。

只提取场景组件，使用独立 React 构建产物接入现有 FastAPI 页面。适配点包括：五个固定模块替换成实际知识库列表；模块计数替换成文档数量及真实关联；扇形笔记替换成知识库文档，点击继续打开已有文档详情弹框。真正库间关联沿用现有接口，不引入示例笔记或原项目个人数据。常规列表、模型管理和工作台不改动。

页面切换保留原版弹簧状态和媒体播放进度；知识库详情间切换时核心球保持位置和大小，仅选中水母及文档分支运动。布局适配动态知识库数量、长文档列表、空知识库和手机宽度。离开场景后释放动画、事件和媒体；支持减少动态效果和后台暂停。

原版复制文件与修改范围、提交标识、授权说明保存在 frontend/neural/来源说明.md；原素材与授权文件随代码保留。验证包括素材哈希一致、前端构建、脚本语法、浏览器媒体播放、知识库切换、文档弹框及列表切换。

## 星团沉浸式全屏布局

星团总览与详情铺满主导航下方的可用视口，移除外层卡片边框、圆角和固定黑色矩形背景。原版场景背景成为页面唯一底色，标题、统计、搜索及操作按钮以透明覆盖层排列；常规列表保持原排版。

桌面两侧保留随视口变化的 24–64 像素安全距离，手机保留 18 像素；场景布局预留顶部工具区与底部图例区，核心球、水母标签和文档节点均按安全区域分布。详情切换的核心球位置依然固定。

场景高度随可用视口变化；文档较多时按可见高度分页，避免节点重叠或挤出屏幕，分页不重新播放核心球入场。关联依据使用底部浮层显示，列表切换、文档弹框与原版视频动效保持。
# 知识工作室阅读与管理扩展

顶部保留三个居中主菜单，增加轻量控制中心按钮，集中提供索引任务、用量统计、云端空间、服务设置。复用现有水母视频和场景动效，不改写星团素材。

星团节点、常规文档列表及工作台侧栏统一打开宽屏阅读室：左侧目录、右侧原始 PDF／按页提取文本／章节摘要；支持目录跳页、页码、整页／适宽／放大、引用定位和多格式导出。手机布局将目录压缩为可横向浏览的节点，正文独立滚动。旧的纯摘要文档弹框实现及专属样式已移除，共享模型弹框样式保留。

阅读室管理提供重命名、移动、重建索引和删除；知识库管理提供重命名、删除。上传先展示索引方案与模型职责，高级参数折叠，非当前模式参数不可编辑。任务由真实阶段驱动，失败／取消保留旧索引。问答工作台显示文档范围、检索方式、停止生成、检索轨迹、来源卡片和实际用量，历史会话继续呈现这些信息。

云端未连接时显示独立配置引导，连接后可进入多级目录、翻页浏览文档、声明元数据规则、显式上传本地 PDF、阅读云端结构并查看页图／内嵌图／块级高亮。没有连接不显示虚构云端数据。


## 问答区域细化（current）

检索状态、当前处理阶段、模型输入入口与调用统计合并为统一面板，检索明细按需展开。流式刷新保留用户的展开状态；等待回答使用轻量圆点提示，回答正文采用留白阅读布局。问题气泡根据内容收紧宽度。

文档范围、检索方式和停止按钮移入输入框顶部，与正文输入、所属知识库及发送按钮形成统一操作区；停止按钮仅在生成期间显示。统一消息区与输入区域的宽度、圆角和边距，提升正文、状态标题和引用来源的可读性。保留深灰绿与香槟金，动效尊重减少动态效果偏好。

使用隔离资料检查检索中、已完成、明细展开、模型输入弹窗与 390px 手机布局；不发起模型请求，不向用户会话写入演示数据。前端脚本语法检查通过。
