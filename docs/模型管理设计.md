# 模型管理设计

## 页面与交互

顶部“知识工作台／知识库／模型”胶囊菜单整体水平居中，品牌和运行状态分列两侧。窄屏缩短标签并分配独立导航行，避免品牌挤压菜单。

模型页面延续深灰背景、银灰按钮、香槟金和薄荷绿点缀。页首展示默认对话模型、默认向量模型及配置数量；下方按全部、对话、向量筛选并搜索名称、模型标识和服务地址。支持新增、编辑、删除、设为默认及连接测试。

服务弹框配置服务名称、OpenAI-compatible 协议、base_url 和 api_key，可附首批模型（一行一个标识）。服务下的添加模型弹框配置用途及模型标识，支持批量添加；编辑单个模型时可修改显示名称、用途及标识。密钥本地明文持久化，输入默认隐藏，可手动显示。列表不返回密钥，编辑时按需读取完整配置。配置本地保存到忽略提交的 models.json，不写入知识库与会话文件。

## 默认与兼容

对话和向量各有独立默认项。编辑配置本身不改变用户明确选择的默认项。删除默认模型时自动改用同类剩余第一项；没有剩余项时，对话退回原环境配置，向量显示未配置。

工作台侧栏使用已保存对话模型下拉框，可为后续问答与上传索引选择模型。设为默认后同步工作台选择；已有索引和历史消息不重算。

原 API 的 model 参数和环境变量调用继续有效；新 model_id 参数使用已保存配置。没有显式选择时使用已保存默认对话模型，无配置时回到旧环境变量模式。现有 CLI 不受 Web 模型选择影响。

## 调用与并发

用 ContextVar 保存本次调用的模型配置，不全局修改环境变量。Web 问答和索引中的同步、异步模型调用读取本次配置；索引线程池显式传递上下文，避免同时使用不同服务时串用密钥或地址。

对话通过 OpenAI-compatible chat/completions，向量通过 embeddings。向量配置用于管理与连接测试，当前树检索不接入新的向量数据库或更换检索链路。

## 接口与验证

模型配置提供列表、单项读取、新增、更新、删除、独立默认项更新与连接测试接口。验证类型、名称、模型标识及 HTTP(S) 服务根地址。连接测试发起最小的对话或向量请求，只返回成功、耗时及必要的维度信息；错误响应不返回密钥。

进行 Python 编译、前端脚本语法及页面交互检查；使用临时配置文件与本地模拟兼容服务验证保存、切换、请求参数、同步／异步上下文和连接测试，不调用用户真实付费服务，不修改已有文档与会话数据。

## 协议参考

兼容参数与请求路径参考 [LiteLLM 官方兼容接口说明](https://docs.litellm.ai/docs/providers/openai_compatible)，并使用当前安装版本和本地模拟服务验证。

## 同一服务配置多个模型

### 数据结构

模型配置升级为服务和模型两层：服务保存 id、名称、协议、base_url 和 api_key；模型保存稳定 id、provider_id、显示名称、用途和模型标识。一个服务可添加多个对话或向量模型，服务地址或密钥变更统一作用于其下模型。

旧配置读取时按协议、标准化地址和相同密钥合并服务，保留所有旧模型 id、显示名称及默认选择。不同密钥的相同地址不会自动合并。迁移原子写入 models.json，密钥仍为本地明文。

### 页面操作

模型页按服务分组展示。提供添加服务、编辑共享连接、在服务内添加模型，以及每个模型的测试、编辑、默认切换和删除。服务添加或追加模型支持一行一个标识批量添加；模型可分别设置用途，批量操作在校验完成后一次保存。

删除模型不删除共享服务；服务下仍有模型时不能直接删除服务，避免误删其他模型。对话、向量默认项独立维护，工作台以“服务／模型”区分模型。

### 接口兼容与验证

保留原模型增改查删、测试与 model_id 调用入口；列表继续返回可直接使用的模型展示字段，并补充服务列表。原模型接口中的地址／密钥更新会修改该模型所属的共享服务，新页面通过独立服务接口明确操作范围。

验证旧结构迁移、同地址不同密钥、同服务多模型、批量失败不部分保存、共享连接更新、模型删除、默认切换和实际调用参数。使用临时数据与本地模拟服务，不向真实服务新增猜测模型或写入测试配置。
# 知识工作室模型职责扩展

在原有共享服务与多模型结构上增加 vision 模型用途，兼容 chat、embedding 及已有模型 ID。默认职责新增 index、summary、vision；索引与摘要可选择任意 chat 模型，视觉 OCR 选择 vision 模型。索引未指定时跟随默认对话模型，摘要未指定时先跟随默认索引再跟随对话；显式 environment 保留为环境回退，不因编辑其他模型而重置。模型删除或修改用途时清理失效职责。

网页上传不再复用工作台当前对话选择，改为提交任务时分别指定索引、摘要和视觉模型。摘要调用使用单独上下文，避免索引连接覆盖摘要模型；并发任务不修改进程环境变量。视觉模型测试发送最小图片，以验证图像输入支持。

向量模型用于页面向量匹配和混合检索，缓存绑定原文内容、模型连接、密钥摘要和维度。控制中心可配置每百万 Token 的输入／输出美元单价；按调用时价格估算，任何参与模型未计价时该次费用显示未设置。索引、摘要、视觉及向量用量分别记录并可展开，未返回用量的调用不伪造 Token。

PageIndex Cloud 使用独立连接和密钥，保存在仅当前用户可读的 studio-state.json。配置接口隐藏已存密钥，留空保留，显式选择断开后移除密钥。云端文件只在用户选择具体文件并确认目的服务后上传。
