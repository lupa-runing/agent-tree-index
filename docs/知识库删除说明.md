# 知识库与文档删除

- 星团模式：进入知识库后，右上角“管理”内可删除整个库；点击文档，在阅读室右上角选择“删除”。
- 列表模式：知识库列表行提供“删除”；知识库内的文档列表提供“删除文档”，详情页“管理”内也可删除整个库。
- 知识工作台：原侧栏删除入口复用同一流程，文档删除也需确认。

所有入口先显示确认框，展示具体名称及影响范围，默认聚焦“取消”。取消或按 Esc 不发送删除请求；上传或问答执行中不允许删除，并防止重复提交。

沿用现有 DELETE 接口：删除文档移除其索引和上传文件；删除知识库移除库及全部文档索引、上传文件。历史对话保留，没有撤销功能。删除成功后更新列表、文档数和星团关联；删除当前知识库时返回知识库总览，清除工作台的当前库选择。

原工作台的 deleteKB、deleteDoc 保留为共用流程入口，不另行维护一套确认与刷新逻辑。代码和流程验证使用模拟数据，页面检查只执行取消操作，不删除现有资料。
