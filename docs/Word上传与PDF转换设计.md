# Word 上传与 PDF 转换

## 目标与流程

版本 current。支持直接选择及批量上传 DOCX／DOC，与 PDF／Markdown 共用添加文档入口。Word 上传后进入后台索引任务，先用本机 LibreOffice 转换为 PDF，再复用现有 Flash／标准索引、OCR、表格提取、向量检索、引用与阅读室。转换阶段显示真实任务状态，失败可重试、处理中可取消。

转换完全在本机执行，原始 Word 文件保留。通过独立临时用户配置运行 LibreOffice，避免与桌面会话或并发转换串用配置；对子进程设置超时，取消时结束本任务的进程组。PDF 生成后检查文件有效性和页数，再进入现有解析流程，不以退出码为零作为唯一成功依据。

## 数据与兼容

现有 type 保持 pdf／md 两种解析类型，file_path 始终指向解析用文件。Word 文档额外保存 source_type、source_file_path 和转换时间；doc_name 保留用户上传的 Word 文件名，避免将 Word 下载伪装成 PDF。旧 PDF／Markdown 数据无需迁移。

原始文件导出下载 Word 原件，额外提供阅读版 PDF 下载；阅读室说明页码与引用基于转换后的 PDF。重建索引从 Word 原件重新转换，生成新的 PDF 路径，成功后才替换旧索引及阅读文件，失败／取消保留旧版本。既有用户确认删除流程同时处理 Word 与阅读版 PDF；开发验证不删除用户 uploads／results 中的文件。

任务重试沿用原件路径；新版本增加的是可选字段，旧任务与已有索引继续有效。保留旧同步上传接口的返回结构，并接入同一转换工具；网页默认继续使用后台任务接口。

## 依赖与界面

转换器优先读取 PAGEINDEX_SOFFICE_PATH，再自动查找 PATH、系统 LibreOffice 安装目录及当前桌面运行时中的转换工具。缺少转换器时，上传接口明确提示安装 LibreOffice 或配置工具路径，不将 Word 当纯文本读取。无需新增 Python 转换依赖。

更新文件选择器、格式说明、Word 格式标识和阅读室下载菜单；继续沿用现有样式，不增加额外操作步骤。提示 Word 转换后再索引，页码按 PDF 计算。本机字体和 Word 专有排版可能影响转换后的分页，应可通过阅读版 PDF 核对。

## 验证

不新增仓库测试文件。临时生成含中文标题、横向／纵向合并表格和分页的 DOCX，转换为 PDF 并视觉核对；另验证旧式 DOC。使用临时知识库和断网／本机限制验证直接上传、转换、无模型索引、页图、表格读取、原件／PDF 下载、重建、失败保留、取消与重试；真实用户存储和原文保持不变。

macOS 无界面转换环境显式加载系统中文字体，避免出现文字可提取但 PDF 中汉字不可见的情况；已有 FONTCONFIG_FILE 配置会继续保留。视觉验证同时检查 PDF 页图，不能只检查抽出的字符串。

## 验收记录

- DOCX 与旧式二进制 DOC 已通过实际 LibreOffice 转换；两页中文样例逐页视觉核对，合并表格的表头、金额与地区对应关系保留。
- 后台上传、真实 Flash 无模型索引、页图、结构化表格、Word 原件与阅读版 PDF 下载已通过隔离接口验证；原件下载字节与上传文件一致。
- 从原件重建成功后使用独立 PDF 路径；模拟转换失败保留旧索引，任务重试可完成。转换中取消和超时均结束本任务进程组，不发布未完成的阅读文件。
- 缺少转换器返回明确的 503；损坏／加密容器与不支持格式给出可处理的错误。旧同步上传接口使用同一转换工具；隔离删除仅处理对应原件及 PDF。
- 网页文件选择器直接选 DOCX、任务阶段“Word 转为 PDF”、完成后进入阅读室、Word／PDF 下载菜单及合并表格均已核对；未调用用户模型，用户 store.json 与 models.json 哈希保持一致。
- 修复 PDF 同段落混合字体造成的同行文本乱序，页面解析缓存版本升为 2。原差旅费 PDF 第 12–14 页表格回归验证通过，38 项现有索引测试通过，保留原有 PyPDF2 弃用提示。

转换参数参考 [LibreOffice 官方命令行说明](https://help.libreoffice.org/latest/en-US/text/shared/guide/start_parameters.html)。功能使用独立进程环境加载字体，不修改系统字体或用户的 LibreOffice 配置。

额外通过双任务并发转换与独立配置验证，加密 DOCX 容器会明确拒绝；同行重排只用于水平文字，竖排文字保持原顺序。原件和转换 PDF 均按 600 权限保存。
