# 文档摘要语言

文档详情中的“章节与摘要”展示索引时已保存的模型摘要，并非原始文档全文；前端直接显示保存的文本，不做翻译。

PDF 的叶节点、父节点摘要，Markdown 节点摘要及文档简介，统一要求使用原文的主要语言。中文原文生成中文摘要，模型返回的 JSON 字段名保持不变。标准 PDF 索引为中文目录补充的前置章节命名为“前言”。

提示词更新只影响后续生成，不会自动重写已有索引。2026-11-05 针对《中国药科大学差旅费管理办法》文档，将其已存的 11 条英文摘要译为中文，并将 Preface 改为“前言”；保留原始文件、页码、节点标识和其他业务数据。修复前已单独备份，不调用外部模型，也不重新索引该文档。
