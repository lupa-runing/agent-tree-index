# 知识工作室完整功能设计

## 产品目标与信息架构

版本 current。保持知识工作台、知识库、模型三个主导航及原版星团。将能力集中到三个工作流：文档阅读与证据、后台索引任务、模型与服务设置，不把高级参数堆入主页面。现有资料继续使用 store.json 与 uploads，不迁移为另一套 SDK 存储。

## 功能闭环

1. 文档阅读器：目录、原始 PDF、逐页提取内容、摘要、引用页定位；提取内容保留多层表头与合并单元格，支持复制表格和下载 CSV；导出目录 JSON、摘要 Markdown、提取内容 Markdown／HTML，支持下载原文件。窄屏切换阅读区域，表格局部横向滚动，详见《表格提取与保留设计》。
2. 引用与问答：单篇或多篇范围选择、流式回答、停止生成、检索步骤与读取证据、引用按钮直达原文；每次问答可查看并下载模型调用时的检索原文和完整请求，历史记录保留输入快照关联；使用所有选中章节，不再每篇仅读取第一个命中。
3. 索引任务中心：支持 PDF／DOCX／DOC／Markdown 多文件上传，Word 先在本地转换为 PDF，再复用现有索引流程；提交后立即显示任务，真实阶段、排队、成功／失败／取消、失败重试。支持 Flash／标准、自动／指定 OCR、摘要／简介、书签、树优化、摘要长度和并发、节点页数及 Token 上限；重建成功前保留旧索引，重启中断任务可重试。
4. 模型职责：兼容原 chat／embedding 默认配置，增加索引、摘要及视觉 OCR 默认项；不同用途可共用同一对话模型；保留环境回退。按次记录输入输出 Token、耗时与模型，价格由用户配置，未配置不显示虚构费用。
5. 文档管理：重命名、移动知识库、重建索引、失败重试，删除沿用确认机制；文件不因重命名或移动而删除。
6. 检索：默认保留 PageIndex 树检索；提供向量及混合检索选项，按页向量缓存绑定文件内容和模型连接／标识，模型变化后重建；展示所用模式和证据。无向量模型时明确提示，避免静默冒充向量检索。
7. 云端空间：独立连接设置、目录层级、文档列表、元数据字段规则、显式上传本地 PDF、查看云端结构、页图／内嵌图／块级引用；未连接时引导配置，不把云端能力标成本地能力。所有外发文件须由用户在上传操作中明确选择并确认目的地。

## 架构与兼容

新增 studio_service.py 负责阅读、任务、统计、设置与云端适配，静态 studio.js／studio.css 负责交互。原接口继续可用，网页新上传改为任务接口，问答改用事件流接口。新任务、设置、用量保存在 studio-state.json，使用锁与原子写入；旧文档字段按需读取，新增字段不破坏旧格式。后台任务只持久化模型 ID，不在任务接口输出密钥或磁盘路径。

任务完成写入前重新确认知识库／文档仍然存在；移动／重命名与重建相互协调，防止复活已删除记录。取消为协作取消：模型请求返回后检查标志，不提交结果。流式中止保留部分回答并标记停止，不伪装完成。所有时间返回 UTC 时间戳或带 UTC 标记的字符串。

## 视觉与可访问性

沿用深灰绿、银白、香槟金和低饱和薄荷色；使用侧栏、分段按钮、紧凑工具栏及分层抽屉。任务与用量在统一控制面板，阅读器使用宽屏双栏、手机单栏。模态框有标题、焦点约束、Esc 关闭；危险操作二次确认。复用现有视频和动画，不重画水母。

## 验证与交付

默认不新增仓库测试文件。执行编译、脚本语法检查、临时隔离数据与模拟服务验证，覆盖任务重试／取消／失败保留旧索引、流式与多章节引用、模型角色、导出、移动和云端协议。真实页面验证布局与入口；不为测试调用用户付费模型，不向云端上传用户资料，不清理 uploads／results。现有文件与配置逐项核对，允许用户并发新增资料。

## 实现与使用说明

已接入本地阅读、引用定位、Flash／标准索引、独立模型职责、流式问答、单篇／多篇范围、检索轨迹、OCR 原文、用量与价格、全部高级索引参数及导出。同时实现重命名、移动、重建、后台任务取消与重试，默认树检索及可选向量／混合检索。单篇 PDF 的多个命中章节不再被去重丢弃；显式选择多篇时逐篇检索以覆盖所选范围。

扫描件使用视觉模型提取原文；Flash 无法提取扫描目录时按 OCR 页面提供可检索结构。自动 OCR 遇到视觉服务不可用时保留可提取文字并显示识别提示，全扫描且无识别结果时任务失败；强制 OCR 不静默降级。任务阶段进度不代表逐 Token 的精确百分比。

所有云端路由已按仓库 CloudAPI 接入，并经过模拟适配验证；真实云端需用户配置 PageIndex API Key，尚未替用户连接付费云端或上传资料。用量从升级后的调用开始，历史调用不反推；停止流式请求属于协作取消，后台在当前请求返回／下一片段到达时停止并保留部分回答。模型服务不返回 usage 时不估算虚构 Token。

新增 studio_service.py、static/studio.js、static/studio.css；原 HTTP 上传／问答入口为旧客户端保留。网页统一使用新任务和流式接口。store.json 改为加锁原子写入，索引提交与取消／删除协调，防止提交竞争造成数据复活。未自动重新索引已有资料，未创建或切换分支。
