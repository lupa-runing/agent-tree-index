# 原版星团场景来源与适配

来源：[neural-creator-dashboard](https://github.com/luoluo-121/neural-creator-dashboard)，本地提交 `769d690fa1c06d985926d8f16772d15514b718e1`。

- `Scene.jsx`：直接提取原 `Home.jsx` 的布局目标、弹簧函数、光尘、paintVideo、Scene 帧循环和渲染结构；保留先安排下一帧与非负 dt 的实现。
- `theme.js`、`icons.jsx`：复制原文件；主题素材路径指向 PageIndex 本地静态目录。
- `scene.css`：直接复制原场景、光球、水母、SVG 光线及标签样式，限定作用域。
- `static/neural/media/`：四个原视频／封面按字节复制，素材来源即梦 AI 生成，见上游 README。
- `adapter.jsx`：连接 PageIndex 的知识库数据、真实关联和文档弹框；只适配动态数量、页面尺寸、长列表、空状态、切换状态及资源释放。

原版五模块布局适配为动态知识库；原内嵌分析栏改为 PageIndex 已有文档弹框；详情切换共享弹簧与视频进度，核心球不重播入场。未复制示例或用户笔记数据。

许可原文见 LICENSE、NOTICE.md、licenses/MIT-legacy.txt。React 与 React DOM 许可见 licenses。

构建：在 `frontend` 执行 `npm ci`、`npm run build`，输出 `static/neural-scene.js` 和 `static/neural-scene.css`，Python 服务直接提供静态文件。

全屏适配：场景填满导航下方视口，外层标题与工具为透明覆盖层；布局目标读取顶部／底部安全区，文档超出可见行数时分页，较矮屏幕的知识库标签采用紧凑排版。原视频素材及逐帧绘制、弹簧和脉冲实现保持复用。

详情布局优化：沿用原场景素材和动效，在 adapter.css 中适配半透明文档节点、双行标题、文件信息和悬停阅读入口；根据节点高度计算分页容量。桌面视图调整核心球的安全距离和文档扇形间距，知识库之间切换时核心球目标坐标保持一致。960px 以下采用上方知识库、下方文档的排布，连接线沿左侧空白展开，避免穿过文档标题。知识库列表和文档详情弹框沿用既有行为。
